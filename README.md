


# 🏠 House Price Prediction

A Machine Learning based web application that predicts the estimated price of a house based on different property features such as location, BHK, total area, bathrooms, balconies, area type, and availability.

The application is built using **Python, Scikit-learn and Streamlit** and provides an interactive interface where users can enter property details and get an estimated house price instantly.

## 🎯 Project Objective

The main objective of this project is to develop a machine learning model that can estimate house prices based on important property characteristics.

This project demonstrates an end-to-end machine learning workflow:

**Data Preparation → Feature Engineering → Model Training → Model Evaluation → Model Saving → Streamlit Deployment**

---

## ✨ Key Features

- 🏠 Interactive house price prediction
- 📍 Location-based prediction
- 🛏️ BHK selection
- 📐 Total area input in square feet
- 🚿 Bathroom selection
- 🌿 Balcony selection
- 🏡 Area type selection
- 📅 Availability selection
- 🤖 Machine Learning based prediction
- 📊 Model evaluation using multiple regression metrics
- 🌐 Live Streamlit deployment
- 💻 Simple and user-friendly interface

---

## 📊 Input Features

| Feature | Description |
|--------|-------------|
| Area Type | Type of property area |
| Availability | Property availability / possession |
| Location | Location of the property |
| BHK | Number of bedrooms |
| Total Sqft | Total property area in square feet |
| Bathroom | Number of bathrooms |
| Balcony | Number of balconies |
| Price | Predicted house price |

---

## 🤖 Machine Learning Model

The project uses **Linear Regression** to predict house prices.
